# 提交前检查

此文档是通用检查流程，不记录任何机器的任务名称、账户、定时规则或路径。

1. 运行 `tools/test-local.ps1`，确认构建、界面和候选文件检查通过。
2. 运行 `tools/check-docs.ps1`，确认公开 Markdown 的本地链接可访问、文档使用 UTF-8。
3. 审阅 `git status --short`，确认候选项只有源码、通用工具、占位配置、文档及已说明来源的动画。
4. 明确新增自有代码的整体许可证。不得把上游代码许可扩大解释为角色、声音或语料授权。
5. 按审阅结果选择性暂存，再运行 `tools/check-repository.ps1`。它会同时检查已暂存内容。
6. 查看 `git diff --cached --stat` 和实际差异，确认没有本地记录或禁止资源。

模型／权重不允许进入 Git、Git LFS、Release 或归档附件。原声、训练集、参考音频、机器配置、计划任务导出、自动化状态和私有人设也不应公开。

本地整理计划和检查报告应放在 `local/`，不会成为公开文档。原有的本机准备清单文件同样被忽略。不要强制加入忽略项。

检查脚本不提交、不推送、不安装 Git Hook，也不修改 CI/CD。实际公开操作必须由仓库所有者决定。
