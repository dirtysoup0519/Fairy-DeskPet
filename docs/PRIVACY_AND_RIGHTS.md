# 隐私与版权边界

## 可以进入源码仓库的内容

程序源码、通用构建／启动工具、占位配置、公开精简人设、使用文档，以及附带来源和原始声明的代码生成动画。新增自有代码仍需要项目所有者决定整体许可证。

动画的代码来源与 Apache 声明已核对，但这不表示角色形象、名称或商标得到额外授权，也不表示项目获得官方背书。详细来源见 [第三方说明](../THIRD_PARTY_NOTICES.md)。

## 必须留在本机的内容

- 语音模型、任何格式的权重、检查点、训练数据、参考录音、原作语音及处理后的音频。
- 私有人设、用户关系、对话、API Key、认证文件、机器路径和运行时配置。
- Windows 计划任务导出、任务 XML / JOB 文件、Codex 自动化配置、定时规则、任务主体账户与本地任务清单。
- 本机提交计划、候选清单、检查记录、备份、日志和界面预览。

这些内容通过忽略目录／文件规则排除。候选检查还会检查已暂存文件，防止仅依靠 `.gitignore` 漏掉强制加入的文件。

## 程序会做什么

打开桌宠时可启动或复用本机语音服务；这是桌宠生命周期内的服务加载，不是 Windows 登录计划任务。源码不安装、导出、读取或同步本机的计划任务。待机语音是应用内计时器，不导入系统任务。

向聊天服务发送消息时，文本和当前对话由所选服务处理；开启联网时可调用公开网页搜索。请自行决定向外部服务提供哪些信息。API Key 和短期对话记录在应用进程内保留。长期记忆开启时，会持久化模型文字观察和明确记忆到本机 DPAPI 加密文件，并检索后发送给当前入口；可以查看、停用和确认清空。偏好和合成音频存储位置见 README。

屏幕协作每次启动默认关闭，必须手动开启或点击一次分析才读取。开启后会将选定显示器或全部显示器的完整可见截图（普通对话取新图，自动分析筛选变化）发送至当前模型入口，不是纯本地分析。请避开敏感窗口；本功能不保证自动识别并遮盖所有敏感内容。停止会取消请求、清空帧缓存并丢弃迟到输出，但无法撤回已经发送的图片。Codex 需要短期本地图片文件，异常中止可能有残留；详细数据流与清理说明见 [屏幕协作](SCREEN_ASSIST.md)。

游戏攻略是独立的公开文字检索：只将配置的游戏名、数值章号、枚举区域及问题类别用于搜索，截图和私人记忆不进入搜索词；缓存的攻略来源会作为背景提供给当前选定的视觉模型。可关闭联网或游戏攻略开关来停止检索。

## 检查边界

`tools/check-repository.ps1` 检查本仓库 Git 候选集合，不遍历操作系统计划任务或其他应用的私有目录。通过检查表示该候选集合未命中当前规则，不等于对所有版权问题作出法律保证。

公开前仍应检查实际暂存差异，并确认自有代码的许可证、第三方内容来源及任何另行取得的授权。
