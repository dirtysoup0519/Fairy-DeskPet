# 全屏协作与长期记忆

Fairy 可在你开启后观察完整可见桌面，并在对话时取得新画面。它提供解释与建议，不点击或操作其他软件。这里的实时对话是文字输入结合当前截图，再以字幕和本机语音输出；尚不包含麦克风收音或连续视频理解。

## 使用

1. 构建并打开新版，配置 Codex 或 DeepSeek。朗读需要 README 中的本机语音环境。
2. 右键 Fairy →“屏幕协作设置…”。选择“全部显示器 · 完整桌面”或某个显示器。
3. 单次查看可点“截屏并分析一次”；输入框中已有的问题会作为本次问题。
4. 开启“全屏对话与持续观察”后，每秒在本地更新画面。此后每次普通发送都会重新截图，无须另勾附图选项。关闭后恢复文字对话。每次重启默认关闭采集。
5. 玩游戏时选择“游戏协作”：目标每 0.25 秒本地采样，降低变化阈值，本地保留近期稳定关键帧，画面稳定后按事件分析，可在「设置 → 游戏陪伴」调节主动开口的最短间隔（3～120 秒，新设置默认 15 秒）。开火时按住全局鼠标左键不再阻止分析，只有操作桌宠自身才暂缓。取帧实际速度受硬件限制；推理与朗读仍串行，冷却间隔不是回应延迟保证。普通模式保持原有变化筛选。
6. 在「语音」打开「空闲时播放待机语音」，再在「屏幕协作」开启持续观察并选择「待机陪伴」。每到 1～60 分钟的待机间隔，Fairy 截取一张当前画面，按当前人设生成一句陪伴语音。画面没有合适话题或识别失败时，从普通合成台词里随机选一句。看屏待机期间只自动播放合成语音。
7. 工作协作在画面变化后自动分析，默认冷却 15 秒，可调 5～300 秒。工作和游戏协作的语音由「朗读屏幕分析结果」控制。语音先合成，再显示字幕并播放，主动对话优先。
8. 点击“停止读取与分析”可停止采集、取消请求、清空帧并拦截迟到输出。隐藏、切换入口或改变显示器／模式／分辨率也会停止。锁屏时暂停并清空帧。

看屏待机使用当前配置的识图入口，无须开启「朗读屏幕分析结果」。这类陪伴短句独立于对话和长期记忆。关闭屏幕观察后，待机语音恢复为随机台词。

## 完整画面与更新

原先会遮黑桌宠窗口，现在发送完整的可见屏幕像素，包括桌宠界面。只有本地变化检测会忽略桌宠窗口范围，避免自身动画不断触发分析；发送的图片不因此挖空。其他程序主动保护的窗口、DRM、安全桌面仍可能不可读取，遮挡和最小化的内容也不会凭空变成可见。

可选长边 960／1280／1600／1920 px，默认 1600。全显示器采用 Windows 虚拟桌面范围，显示器之间的无屏幕空隙仍是空白。多屏拼接会缩小文字，必要时选单屏或提高分辨率。普通模式最多保留两张筛选关键帧。游戏模式另在内存保留最多八张缩小的近期关键画面，按时间与最新截图一起提交。

游戏内无需切出：`Ctrl+Alt+F8` 分析当前画面并发送到当前入口，`Ctrl+Alt+F9` 仅在本机截屏预览，不上传。快捷键被占用时设置页会提示，界面按钮仍可用。截图先于预览窗口出现，避免切出游戏后抓到其他窗口。若预览黑屏，可试无边框窗口；当前为 GDI 屏幕采集，不向游戏进程注入代码，也不保证读取独占全屏或受保护表面。游戏回复会标注截图时间与耗时，超过 8 秒的回复会提示是“刚才画面”。

每秒采样不是每秒请求模型。自动分析仅在画面变化且冷却结束时请求，主动提问可立即请求。实际回应还受网络、模型推理和语音合成延迟影响，没有毫秒级保证。画面变化检测仍可能漏掉短暂或细小变化。

## 游戏攻略与 Fairy 陪伴

关键画面回顾和稳定后开口的设计参考 [DSH Game Buddy](https://github.com/sandy1317/dsh-game-buddy/tree/6b8639e525e964acefdc7cf993251c29e289e6d1)。

画面稳定后会检查转场、战斗收尾和探索进展。持续活动时也会送图，间隔取 8 秒和主动开口间隔中的较大值。可在游戏陪伴页查看最近送图与识别、播报状态。运动强度只是战斗的近似判断，部分提示会等画面稳定。每次文字提问或手动截屏分析附上最新画面，以及最近两分钟内最多三张有差异的关键帧。停止、锁屏或切换入口会清除关键帧。同章节与区域的同类失败或完成提醒采用更长的去重间隔，并随开口设置调整，过时的自动战斗和资源提示会丢弃。

可在游戏设置导入本地 JSON 资料库。使用自己编写或有权使用的攻略。格式为 `{"game":"生化危机4 重制版","entries":[{"chapter":1,"hint":"先核对当前目标和附近交互提示。","detail":"可选的本章具体操作","source":"https://example.com/guide"}]}`。游戏名称与版本及章节匹配时优先用本地资料。默认只传提示内容，开启详细解法后才附带 detail。source 和 detail 可省略。

在“设置 → 游戏陪伴”中管理游戏攻略和鼓励。游戏名称默认“生化危机4 重制版”，请核对原版／重制版或改成实际游戏。当前章节填 0 为自动识别；识别不准时可手动指定章节。需要同时打开“允许联网搜索”和“按需自动搜索当前阶段攻略”。关闭任何一个联网开关都会取消在途攻略检索。停止采集、切换入口、锁屏或修改游戏设置也会取消。

流程分开执行：先用无联网工具的图片请求读取画面，返回游戏是否匹配、章节／区域、可信程度、问题类别及简短回复；后台再用文字请求检索公开攻略，不包含截图或私人文字记忆。搜索词只由用户配置的游戏名、数值章号、枚举区域与问题类别组成，不转发屏幕里的任意文字。区域枚举目前针对生化危机4的村庄／城堡／孤岛；其他游戏可按章节检索，尚不支持任意地图区域名称。

只有有明确画面证据时才使用自动章号；不确定时只查通用无剧透技巧。最近明确的进度最多暂留十分钟作为可能过时的背景，确认了新进度或切出所配游戏时会更新／清除。它不是读取游戏存档或内部任务数据，仍可能识别错误；需要精确当前流程时，可展示地图或章节画面，或手动填写章号。

攻略检索不阻塞当前视觉回复。查到后缓存最多 24 个查询、每条有效六小时，仅存在进程内；后续画面仍匹配相同游戏版本与阶段时才使用。默认至少 90 秒才自动发起另一查询，失败后对应查询等两分钟重试；“检索／更新当前攻略”允许手动刷新。搜索必须确实调用工具并有公开来源，才当作攻略就绪；来源可从对话页“来源”查看。找不到或失败时退回画面提示，不编造攻略。

默认只提示思路，不揭晓后续剧情。勾选“允许当前阶段的详细解法”后可提供当前关卡具体步骤，仍要求不透露后续内容。攻略和阶段匹配有模型判断成分，不能保证网页或生成结果完全不含剧透。

鼓励沿用当前本机 Fairy 人设和称呼，冷静、克制、先帮忙再安慰。只有画面给出失败、阶段成功、危险或卡关等依据时才考虑，专门鼓励使用开口间隔的 6 倍；同一帧不会不断喊话。可单独停用鼓励。没有有用新信息时仍可保持安静。

`--test-game-guide` 是可选真实 Codex 搜索检查：只提交公开的游戏／阶段查询，不读取屏幕或私人记忆，需要既有登录并消耗额度。默认自检使用合成资料验证进度不确定时降级、搜索词过滤、来源门槛、缓存到期、重试和鼓励限频。

## 任务与记忆

从对话界面的「管理」或「设置 → 任务与记忆」进入。选定任务后，可以新建、重命名、删除任务，以及查看或清空所选任务的长期记忆。编辑任务名称时，Enter 换行，Ctrl+Enter 确认。删除自建任务需要确认，并会清除该任务的对话、草稿和长期记忆。默认任务始终保留，其长期记忆可以单独清空。

任务列表和当前任务会在重启后恢复。每个任务各自保存加密记忆，并可独立启用、查看或清空。默认任务沿用现有的记忆文件，新任务从空白记忆开始。对话记录、草稿和最近回复在本次运行期间保留。

“长期记忆”独立控制读写，默认开启；但采集仍默认关闭，没有分析就不会产生屏幕观察。保存模型返回的简短文字观察和以“记住：”开头的明确记忆，不保存截图。自动记录带时间、标为模型观察，可能判断有误；当前画面优先，不能把历史状态当作当前事实。模型没有返回合格观察时不记入。

默认任务的记忆位于 `%LOCALAPPDATA%/CodexFairyPet/memory/screen-memory.dat`，其他任务保存在同目录下的 `tasks/<任务ID>/screen-memory.dat`，使用 Windows DPAPI 按当前用户加密，最多 500 条；超限淘汰最旧条目。它不是跨设备云同步，换 Windows 用户或重装系统后可能无法解密。损坏时保留原文件并暂停写入，不静默覆盖。

对话会按问题关键词检索相关记忆，并加入最近观察；最多取 8 条作为背景，发送给当前选定的模型入口。Codex 和 DeepSeek 共用本机这份记忆；即使暂时关闭画面读取，长期记忆开关开启时仍可回忆过去的文字背景。

可以“查看记忆”，停用后不再读写，或点击“清空记忆…”并确认后清空。停用不等于清空。会过滤明显的密码／验证码／密钥／身份资料／邮箱／机器路径等文本，但这不是可靠的全自动隐私识别；普通工作摘要本身也可能包含私人信息。

## 模型与资料边界

- DeepSeek 图片通过官方聊天接口的 `image_url` PNG base64 发送，默认看图型号 `deepseek-flash`；见[官方 Vision 文档](https://api-docs.deepseek.com/guides/vision/)。文字模型不一定支持图片。
- Codex 使用现有登录的 CLI，通过 `codex exec --image` 提交临时图片；图片参数与 stdin 参数用 `--` 分开，避免把 `-` 当成第二张图片。见[官方 CLI 文档](https://learn.chatgpt.com/docs/cli/reference)。
- 附图请求关闭网页工具；游戏攻略通过独立的公开文字请求联网，截图和私人记忆不进入搜索词。不允许 shell 或 computer-use。画面和历史记忆中的文字均为非可信资料，不能授予操作权限。
- 开启或单次分析会将完整画面发送到所选入口并消耗对应额度。不会自动遮盖其他软件中的秘密，敏感画面出现前应停止读取。
- DeepSeek 图片在请求内存中；Codex 临时 PNG 在本机 `screen-cache/`，完成／取消后尝试清理。异常退出或占用可能留下临时图片。停止无法撤回已发送内容，服务商和 CLI 的缓存政策不由桌宠控制。
- 截图不进入源码、文字历史或长期记忆。加密记忆和截图目录均被 Git 忽略和候选检查拦截；禁止上传真实桌面截图、私人记忆、模型、权重和录音。

## 验证

`tools/test-local.ps1` 构建并运行自检、界面渲染、屏幕与记忆测试，默认只用合成画面，不采集真实桌面或请求收费接口。检查完整像素保留、自身动画过滤、关键帧上限、冷却、取消、图片协议、加密与重启记忆、去重、500 条上限和损坏保护。

`--test-live-screen` 是显式的真实屏幕本地诊断：取两帧比较，将一次 PNG 与亮度／变化指标写入本机 `screen-cache/live-game-check.*`，不会上传，不属于默认测试；该私有截图会保留，不能提交源码。

`--test-screen-codex` 可发送合成测试图片验证真实 CLI，需已有登录并消耗额度。测试图片留在忽略目录。开发时可 `./build.ps1 -OutputName FairyPet.UiCheck.exe -UiCheck` 构建交互测试实例，使用独立的 `preview/interactive-check` 数据，不覆盖用户偏好；该实例仍需从界面明确点击或开启才采集，关闭其设置窗口的 × 会退出测试实例。

参考 [dsh-see-now](https://github.com/SAOS-3624/dsh-see-now) 的变化筛选思路，版本 `c1af8c9ad623d368396ac35b9ea2aa4cf306e7c4`；在 C# / WPF 中实现简化管线，不依赖其 FFmpeg 或 Node.js 环境。Apache 声明保留在 `licenses/dsh-see-now-LICENSE.txt` 和 `licenses/dsh-see-now-NOTICE.txt`。上游 NOTICE 的“不上传”等描述仅适用于上游自身范围，不代表本应用不向模型发送截图。
